DATA FLOW:
                                                      
    1. Load HEX File
       User taps Load → FilePicker → Read file
       → HexParser.parse() → Cpu8051.loadProgram()
       → SimulatorProvider.notifyListeners()
       → UI rebuilds with program loaded

    2. Execute Instruction
       User taps Step/Run → SimulatorProvider.step()
       → Cpu8051.fetch() → Cpu8051.executeInstruction()
       → Update RAM/Registers/Flags/PC
       → SimulatorProvider.notifyListeners()
       → UI rebuilds with new state

    3. View State
       UI watches SimulatorProvider
       → Calls getRegistersMap() / getRamCopy()
       → Displays current CPU state
       → Highlights current PC in code
       → Shows changed memory locations

    0x08-0x0F   Register Bank 1
    0x10-0x17   Register Bank 2
    0x18-0x1F   Register Bank 3
    0x20-0x2F   Bit-addressable RAM
    0x30-0x7F   General purpose RAM
    
    0x80        P0 (Port 0) *
    0x81        SP (Stack Pointer)
    0x82        DPL (Data Pointer Low)
    0x83        DPH (Data Pointer High)
    ...         (Other SFRs)
